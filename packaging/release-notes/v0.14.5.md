## New

- **Real word timing where available.** Lyrics now try Better Lyrics TTML before the existing Spotify/LRCLIB fallback. The karaoke highlight uses the provided word and syllable timestamps, holding still through gaps between words.
- **Existing lyrics keep working.** Missing word timings, authentication limits, timeouts and provider failures fall back to the existing lyrics. Old cache entries do not prevent word-timing lookups.

Better Lyrics receives only song title, artist, album and duration. No Spotify credentials or Soloist key are sent. Coverage varies; line-only lyrics retain the estimated sweep. Reduced-motion mode keeps a steady highlight.
