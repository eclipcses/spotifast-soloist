Spotifast Soloist 0.14.3 combines upstream Spotifast 0.14.2 with optional
official Soloist playback on Windows x86_64.

## New

- **Use Soloist behind Spotifast's interface.** Settings → Playback → Soloist
  playback starts your separately downloaded Spotify Soloist executable,
  saves your key in Windows Credential Manager, and retains pairing across
  restarts. Select its Connect device to play. By @eclipcses.
- **Updates stay on this fork.** Releases are built by GitHub Actions and
  their checksums are verified using this fork's Ed25519 publisher key.
- **Windows downloads include a portable ZIP, MSI and setup EXE.** Soloist
  itself is not bundled. MilkDrop is omitted because it cannot consume
  Soloist's audio.

## Fixed

- **Keep Soloist changes when updating Spotifast.** The app checks
  eclipcses/spotifast-soloist instead of the original project's releases.
- **Stop and forget really forgets setup.** A revocation marker prevents a
  failed Windows credential deletion from restoring the old key next time.

Upstream 0.14.2 requires your own Spotify app's Client ID for sign-in; the
app guides you through creating it. This differs from your Soloist API key.
The equalizer, audio visualizers and local-player-only queue operations do
not apply to Soloist. Its official builds still expire after 90 days.
Playback with your account and RAM savings are not established by CI tests.
